Make it yours (optional)

Tint the flame or resize it right on the script tag:

<script src="https://byteling-baas-417f0fd8.base44.app/embed.js" data-hue="210" data-size="150"></script>
OptionWhat it does
data-hueFlame color, 0–360 (e.g. 210 = blue, 150 = green). Default is warm amber.
data-sizeLantern size in pixels (48–240). Default 72. Users can also drag & resize it themselves via the ⚙ menu.

Want to place it in a specific spot instead of auto-corner? Add the tag yourself: <byteling-companion hue="210"></byteling-companion> — the script will use that one instead of adding its own.

What your visitors need

🔑

Each person clicks Sign in in the panel, then adds their own Anthropic API key once. From then on Byte-ling reads their GitHub repos, answers questions about their code, and opens pull requests — all billed to their account, not yours. You never touch keys or run a backend.
