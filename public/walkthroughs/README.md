# Walkthrough GIFs for the install page

Drop short screen-recording GIFs here to light up the "Paste it" walkthroughs on
`/install.html`. Each slot appears automatically **only if its file exists** — no
code change needed. If a file is missing, the page just shows the text steps.

## Filenames (exact)

| File                  | Platform panel it fills |
| --------------------- | ----------------------- |
| `base44.gif`          | Base44 (record this one first — it's the main audience) |
| `wordpress.gif`       | WordPress |
| `wix.gif`             | Wix |
| `squarespace.gif`     | Squarespace |
| `html.gif`            | Plain HTML |
| `react.gif`           | React / Next |

## Recording tips

- Show the whole journey in ~10–15 seconds: **open the right place → paste the
  line → save/publish**.
- Record at a readable width; the page displays them full-width up to 760px, so
  **~760–1000px wide** looks crisp without huge files.
- Keep each GIF under ~3 MB if you can (trim, 8–12 fps) so the page stays fast.
