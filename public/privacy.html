Privacy Policy

Last updated: July 24, 2026

Byte-ling is a coding companion you can use in the web app, as an embedded widget on your own site, or as a Chrome extension. This policy explains what data Byte-ling handles and why. It applies to all three. The guiding principle: Byte-ling works on your own accounts and your own API key — it is a tool you point at your code, not a service that collects your data to resell.

What we handle

  • Your account — an email address, used to sign you in and to scope your data to you.
  • Your GitHub connection — when you connect GitHub, we store an access token (granted with the repo scope you approve) so Byte-ling can read the repositories you ask about and open pull requests when you confirm them. We never write to your default branch — pull requests only ever land on a new branch.
  • Your Anthropic API key (BYOK) — you provide your own key. It is validated, then stored server-side and never shown back to any browser. All AI usage bills to your Anthropic account, not ours.
  • Your conversations — the messages you send and the repository context you choose to include, so Byte-ling can answer and so your thread survives a reload.

How your code and messages are used

When you ask a question, the relevant repository content and your messages are sent to Anthropic's API under your own key to generate a response, and to the GitHub API under your own token to read files or open a pull request you confirmed. These are the two external services Byte-ling relies on. We do not sell your data, show ads, or use your code or conversations to train any model.

The Chrome extension specifically

The extension uses the narrowest permissions that let it work:

  • activeTab + scripting — only when you click the toolbar icon, it injects the Byte-ling companion into the page you're looking at. It does not run on pages you didn't summon it on, and it does not read your browsing history or the content of pages you visit.
  • host_permissions for the Byte-ling backend — so the companion can talk to the same backend as the web app to sign you in and answer questions.

Where it's stored

Data is stored in Byte-ling's backend (hosted on Base44) and scoped to your account. Sensitive values — your GitHub token and your Anthropic API key — are locked so that only server-side functions can use them; they cannot be read back by any browser, including your own.

Your control

  • Disconnect GitHub at any time from the setup screen — this removes the stored token.
  • Replace or remove your API key from the setup screen.
  • Request deletion of your account data by emailing us (below).

Children

Byte-ling is a developer tool and is not directed to children under 13.
